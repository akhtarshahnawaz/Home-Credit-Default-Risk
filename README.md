# Home Credit Default Risk
This repository contains my solution for the Kaggle **Home Credit Default Risk** competition. The objective was to predict whether a loan applicant would experience repayment difficulties using historical application, credit, and behavioral data.

The project explores multiple machine-learning approaches, including logistic regression, Naive Bayes, tree-based models, feature selection, model blending, and stacked ensembles. It also contains experiments with engineered features, different model configurations, and a final submission pipeline.

Through this competition, I gained practical experience in working with large relational datasets, handling missing and imbalanced data, designing predictive features, evaluating models using ROC-AUC, and combining diverse models to improve overall performance.
